I build **autonomous mobile robots, ROS 2 applications, and AI-powered robotic systems** — from robot modeling and simulation to control, localization, navigation, and perception. My focus is on turning robotics software into reliable, real-world behavior.

- 🔭 Currently building autonomous mobile robot platforms: SLAM, Nav2 navigation, and computer vision.
- 🌱 Deepening my work in digital twins, `ros2_control`, and sensor fusion.
- 🧰 Daily tools: ROS 2, C++, Python, Gazebo, RViz2, OpenCV, and embedded systems.
- 🎯 Goal: engineer intelligent machines that solve real-world problems.

## 🚀 Featured Projects

| Project | What it does |
| :--- | :--- |
| [**Bug-Bot**](https://github.com/AhmedGaberAG/Bug-Bot) | ROS 2 autonomous mobile robot platform with digital twin simulation, differential-drive control, localization, SLAM, Nav2 navigation, safety systems, and computer vision. |
| [**Panda-Bot**](https://github.com/AhmedGaberAG/Panda-Bot) | ROS 2 restaurant delivery robot combining intelligent navigation, SLAM, computer vision, touchscreen control, and multi-sensor perception. |
| [**Mobile-Robot**](https://github.com/AhmedGaberAG/Mobile-Robot) | ROS 2 workspace for robot descriptions and simulation-ready digital twins using URDF, Xacro, TF2, RViz2, Gazebo, `ros2_control`, and sensor plugins. |
| [**ros2_ws**](https://github.com/AhmedGaberAG/ros2_ws) | Hands-on ROS 2 fundamentals: nodes, topics, services, actions, QoS, lifecycle, executors, custom interfaces, and launch files. |
| [**turtle_ws**](https://github.com/AhmedGaberAG/turtle_ws) | ROS 2 TurtleSim project practicing nodes, topics, services, parameters, remapping, launch files, and multi-node communication. |
