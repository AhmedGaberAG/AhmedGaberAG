## 🧭 About Me

I engineer **autonomous mobile robots and AI-powered robotic systems** — owning the full
stack from robot modeling and simulation to control, localization, navigation, and perception.
My focus is turning robotics software into **reliable, real-world behavior**.

- 🔭 Currently building autonomous mobile robot platforms with **SLAM, Nav2 navigation, and computer vision**
- 🌱 Deepening expertise in **digital twins, `ros2_control`, and multi-sensor fusion**
- 🧠 Strong foundation in **control systems, embedded software, and object-oriented C++**
- 🎯 Mission: engineer intelligent machines that solve real-world problems

## 🎯 What I Do

| Domain | Focus |
| :-- | :-- |
| **Robotics Middleware** | ROS 2 nodes, topics, services, actions, QoS, lifecycle, executors, custom interfaces, launch |
| **Modeling & Simulation** | URDF / Xacro, TF2, Gazebo, RViz2, simulation-ready digital twins |
| **Control & Navigation** | Differential-drive control, `ros2_control`, SLAM, Nav2 path planning |
